# カード#28: md プレビューの装飾

ユーザー要望（m01580）: 「mdファイルのプレビュー、マークダウン装飾してほしい」

## 現状（実測）
- `/api/deliverables/<proj>/<id>/view` → `sendFileView`（`src/api/routes.ts:634`）が md/txt/csv/json/yaml を
  `<article class="md">${md(text)}</article>` で包む。
- `src/core/markdown.ts:8` の `md()` は bold / `[x](http)` / inline code / `- ` のみ。
  見出し・コードブロック・テーブル・引用・番号付きリスト・hr・画像・斜体・打消し線は未対応で、
  残りは `<br>` 連結の生テキスト（`# head` が literal に出る）。
- `VIEW_CSS`（`src/api/routes.ts:625`）は `.md` の padding と inline code の背景だけ。
- セキュリティ不変条件: ブロック検出は生行（`> ` の引用に必要）、テキストの出口は `inline()` か `esc()`。
  だから raw HTML は通らない。リンクは http(s) か相対のみ、C0 制御文字を含む URL は不可。
  200k 個の `[` で二次時間にならないこと（`tests/unit/core-markdown.test.mjs:61` が固定）。
- `web/md.js` は v1 ダッシュボード（`web/dash/_app.js:242`）用の別実装。**触らない**。

## 方針
依存追加なし（marked 等は入れない）。`md()` をブロックパーサに作り直し、CSS で装飾する。
サポートする記法:

| 記法 | 出力 |
|---|---|
| `# ` 〜 `###### ` | `<h1>`〜`<h6>` |
| ``` ``` ``` / `~~~` フェンス | `<pre><code>`（中身はエスケープのみ、インライン処理しない） |
| `---` / `***` / `___` | `<hr>` |
| `> ` 連続行 | `<blockquote>`（内部は段落/リスト/見出しを簡易処理。再帰は深さ8で打ち切り、以降は残りの `>` をエスケープしたテキストとして出す） |
| `\| a \| b \|` + `\|---\|---\|` | `<table><thead><tbody>` |
| `- ` / `* ` / `+ ` | `<ul>` |
| `1. ` / `1) ` | `<ol>` |
| `![alt](url)` | `<img>`（相対 or http(s) のみ） |
| `*x*` / `_x_` | `<em>` |
| `~~x~~` | `<del>` |
| 既存: `**x**` / `` `x` `` / `[x](http)` | 据え置き |

段落: 連続する非ブロック行は `<p>` にまとめ、行間は既存どおり `<br>`（見た目を変えない）。

## 不変条件（壊したら差し戻し）
1. すべての出力経路が `inline()` か `esc()` を通る（ブロック検出は生行、テキストの出口は必ずエスケープ）。
   だから raw `<script>` が出力に現れない。
2. リンク・画像の URL は `http://` / `https://` / 相対（`./` `/` なしの素のパス可）のみ。
   `javascript:` `data:` `vbscript:` はリンクにしない。
3. 200k の `[` で 2 秒以内。
4. フェンス内の `**` や `[x](y)` はインライン変換しない。
5. 空文字は空文字。

## 実装順
`inline()` はコード/リンク/画像をプレースホルダ（`\uE000<n>\uE001`）に退避してから
強調系を適用し、最後に復元する（URL 内の `*` を壊さないため）。

## 検証
- `node --test tests/unit/core-markdown.test.mjs`（見出し/フェンス/テーブル/引用/ol/hr/img/em/del/段落 を追加）
- `npm run test:v2` 全通過、`npm run typecheck:v2`
- 実ブラウザ: 8789 の nous 成果物 #2（chat-flow.md、見出し・コードブロック・表を含む 24KB）で表示確認

## やらないこと
- シンタックスハイライト（依存が必要）
- `web/md.js` の同期（v1 の遺物）
- 脚注・定義リスト・HTML インライン許可
